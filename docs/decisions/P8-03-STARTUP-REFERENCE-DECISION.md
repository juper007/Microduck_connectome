## Scientific question and requirements

SCIENTIFIC_QUESTION: When the robot is already in a valid stable operating state and demonstrably moving, do static or receding nonapproaching visual stimuli cause false healthy MaleCNS/DNp01/EscapeDecoder neural stops? This is separate from simulator initialization.

- SCIENTIFICALLY ESSENTIAL: measured moving body and fresh positive applied vx before arm; valid robot-relative nonapproaching image geometry; unchanged RGB/ToF, graph-v2, DNp01 decoder, 1,000 ms scored window, false-positive definition, and 20+20 denominator.
- SAFETY ESSENTIAL: healthy robotd and policy, bounded posture/motion, SafetyClamp, Watchdog, deadman, stop authority, zero safety violations. robotd owns motors.
- REPRODUCIBILITY ESSENTIAL: official fresh down/up, prospective settled reference rule, pinned hashes, complete raw pose/visual/neural/command ledger and attempt accounting, deterministic scorer, independent review.
- SIMULATOR-CONVENIENCE / HISTORICAL ASSUMPTION: matching one historical reset's absolute world pose. It served comparability, not the nonapproaching stimulus definition.

The frozen [P8-V2 protocol](../tasks/P8-V2-FINAL-PROTOCOL.md) defines static distance 0.85 m and receding distance 0.85 + 0.20t m from EACH measured trunk pose, and rejects a world-fixed sphere because it would optically loom as the body walks. [P8-03 geometry](https://github.com/juper007/Microduck_connectome/blob/89ae0f479dd0ef68207083fd30cf29b5499efee1/microduck_connectome/p8_03_geometry.py) uses measured x/y plus range times cos/sin of measured heading. [Trial rendering](https://github.com/juper007/Microduck_connectome/blob/89ae0f479dd0ef68207083fd30cf29b5499efee1/scripts/p8_03_trial.py) supplies RGB/ToF to the controller; [scoring](https://github.com/juper007/Microduck_connectome/blob/89ae0f479dd0ef68207083fd30cf29b5499efee1/scripts/p8_03_score.py) uses evaluator-only geometry. Absolute world translation/yaw cancel in the intended relative geometry, provided actual per-frame range, bearing, and image area remain valid.

## A / B / C decision

ABSOLUTE_REFERENCE_NECESSITY: NOT_ESSENTIAL. No identified scientific or safety dependency on exact R1 RS00 world pose. The CURRENT frozen protocol still requires it until a new version passes review.

LOCAL_REFERENCE_VALIDITY: YES, CONDITIONALLY. A new protocol may preserve the null if official startup completes, a prospectively defined healthy settled post-startup pose is the per-reset local reference, then measured movement and nonapproaching relative image geometry hold. This is a coordinate/reference-semantics change, not widening a threshold. It requires independent scientific and safety review before execution.

OPTION_A: Keep exact absolute reference/tolerances/fresh-reset gate. Evidence does not support its necessity. It would require additional correction and 60-reset qualification work. Do not launch R8 automatically.

OPTION_B: SELECTED. Separately version the reference semantics. Preserve official down/up and policy; define stable settled health/posture/pose and sample-age criteria before capturing each local reference. Keep moving-body/fresh applied vx before arm, relative target geometry, raw lineage, controller, safety, scorer, thresholds, and all 40 trials. Retain at most three fully logged pre-arm acquisition attempts per ID under the frozen exogenous-only rule; never exclude an armed failure.

OPTION_C: No decision-critical unknown remains. Joint/actuator cause is academically useful but not needed for A versus B. ADDITIONAL_DIAGNOSTIC_REQUIRED: NO. No correction attempt or diagnostic cascade.

SELECTED_OPTION: B.
RATIONALE: The experiment measures response to nonapproaching robot-relative input after valid operation. The historical absolute anchor came from one reset. R6/R7 locate the troublesome variation in official startup and show measurable settled endpoints; neither licenses weaker safety or behavioral criteria.

SCOPE_CREEP_ASSESSMENT: YES. R2–R5 pursued yaw correction and actuator mapping to satisfy the absolute reset convention; R6/R7 characterized startup. Further actuator root-cause work would become general MicroDuck stand-up dynamics research. NECESSARY_FOR_P8_03: safe settled startup, measured movement, correct nonapproaching imagery, neural false-stop scoring, complete raw accounting. NOT_NECESSARY_FOR_P8_03: recreating R1 RS00 world coordinates or explaining joint-level stand-up cause. INTERESTING_BUT_DEFERRED: joint policy mechanism, yaw response asymmetry, general reset determinism.

UNCHANGED_REQUIREMENTS: robotd motor authority; health/posture/motion and safety boundaries; RGB/ToF, 20 Hz visual and 50 Hz neural/control; graph-v2 and DNp01 threshold 0.5; Watchdog, SafetyClamp, deadman and stop; static 0.85 m / receding 0.85+0.20t geometry; static ±0.005 m / receding frame step ≥−0.005 m; 1,000 ms scored window; any healthy neural stop is false positive; contamination cannot be a clean negative; 20 static + 20 receding, ≤1/20 each and ≤2/40 pooled; zero safety violations; no post-result threshold tuning; no failed historical ID reuse.

CHANGED_REQUIREMENTS (PROPOSAL ONLY): Replace historical world-pose comparison with a measured per-reset settled post-startup local pose and explicit prospective health/posture/settling/relative-geometry validity gates. Version protocol, harness, manifest, and fresh development/final ID matrix. No acceptance threshold changes.

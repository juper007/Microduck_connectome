## Prior evidence and single changed factor

The retained V2 screen at source `1e6f0abf47ebd97683bdcae403eb2200f2d7c290`, indexed by commit `9db8767`, tested 54 cases with development seeds 885301–885303. A, B, and C each produced 3/3 preboundary neural stops at both required resolutions and zero static/receding stops, but each failed the same paired timing gate at seed 885302. At 65×33, binary RGB frames at 2.6, 2.7, and 2.8 s were identical (`target_area=0.06946387`); at 129×65, areas rose `0.06308885 → 0.07310674 → 0.08455575`. The low-resolution first looming and DN threshold lagged 200 ms, beyond the prospectively frozen 100 ms gate. Both resolution peaks saturated at LPLC2=1.0, so peak equality alone cannot establish representation independence. Preserve this negative evidence and its raw hash; do not reinterpret it as a pass.

**V2.1 hypothesis:** preserving fractional edge coverage in the synthetic RGB representation lets the existing relative log-area estimator see physical expansion before whole pixels change. The only intended functional changes are a new `render_fractional_pixels` renderer and `FractionalRedTargetDetector`, selected together through versioned wiring. Legacy binary renderer, `CameraTargetDetector`, V1 looming estimator, and prior evidence retain their meanings. No graph, neural, decoder, safety, boundary, or stop-transport adjustment is part of this comparison. This is an engineering visual representation choice, not a biological claim.

## Frozen V2.1 visual and sensory algorithm

For the same virtual sphere geometry, pose, bearing, FOV, RGB image size, and virtual trajectory as V2, calculate projected disk radius in pixels as `max(1.0, asin(sphere_radius / center_distance) / half_fov * (width - 1) / 2)` **without rounding the radius**. Retain the legacy rounded integer disk center. Treat pixel `(x,y)` as a unit square centered at those integer coordinates. Set fully outside squares to `(0,0,0)` and fully inside squares to `(255,0,0)`. For an edge square, take exactly 64 subpixel samples with x/y offsets `(i+0.5)/8 - 0.5`, `i=0,…,7`, and count a sample as covered when its squared distance to the disk center is `≤ radius²`. Emit `(round(255 × covered/64), 0, 0)` using Python's integer `round` ties-to-even behavior. Fix iteration and rounding semantics in tests; do not vary subpixel count after seeing results.

The V2.1 detector validates integer RGB triples in `[0,255]`. Include red intensity only where green and blue are zero; there is no positive-red threshold other than total included red `>0`. Set `target_area = sum(red)/(255 × width × height)`, `centroid_x = sum(x × red)/sum(red)`, and normalize target x with the legacy width-based `[-1,1]` mapping. Valid zero-red frames yield neutral/no target; valid detections have confidence 1.0. Invalid frames retain existing neutral/reset behavior. The selected V2.1 pipeline injects this detector and the frozen A estimator into the existing compositor; it does not change SensoryMapper's `LPLC2 amplitude = looming` rule.

Estimator A remains `clamp(max(0, [ln(a_t+1e-6)-ln(a_prev+1e-6)] / dt) / 0.5, 0, 1)`, with `dt` in seconds. Zero area or invalid/no-target clears history and outputs zero; first valid sample after reset outputs zero; a gap `>150 ms` makes the arriving sample a new zero-output baseline. Its output range stays `[0,1]`. Keep graph-v2 SHA256 `c4160c42941163079b6b569d117bf67afcf8b45eaa128c444f7c96c2567593cc`, MaleCNS IDs, graph weights, `neural_model_v1`, EscapeDecoder threshold **0.5**, SafetyClamp, Watchdog, `robot.stop`, robotd motor authority, and evaluator-only center-distance boundary **0.25 m** fixed. No gain retuning or threshold lowering is allowed.

Before execution, freeze the V2.1 source/protocol commit, renderer/detector/estimator config hashes, scenario geometry, seed order, raw output paths, graph and upstream hashes, and metric extractor. No V2.1 seed may be inspected while choosing these values. A code or rule change after results requires a new protocol version and fresh development seeds; retain all earlier raw results.

## Paired deterministic internal screen at 10 Hz

Use **885401, 885402, 885403**, with approach arm elapsed times **2.0, 2.6, 3.0 s** in that order. For each seed, run identical virtual approach geometry at **65×33 and 129×65**, resetting visual, estimator, and neural state per case. Run **static and receding** controls for each seed and resolution. Execute both the legacy **binary renderer + legacy detector + A** and new **fractional renderer + fractional detector + A** on the same cases, giving **36 total cases**: six approaches and twelve controls per representation. Binary rows are a descriptive matched baseline; only the fractional rows enter V2.1 promotion gates. Within either representation, the paired resolution comparison changes image size only. Optional 97×49 results are exploratory and cannot replace either required resolution. Keep all frame intervals at 100 ms and all geometry, camera validity, graph, decoder, and safety settings identical across matched cases.

Trace the complete internal path RGB → fractional detector → A looming → PerceptionFrame → SensoryMapper/LPLC2 → graph-v2 → DNp01 → EscapeDecoder. Record per case: RGB hash; fractional area and centroid sequence; first changed RGB and first positive looming time; positive frame count and looming/LPLC2 peaks; DNp01 peak and first ≥0.5 time; first healthy neural stop; virtual distance and `distance − 0.25 m` at first looming, threshold, and stop; runtime health. This fixed-pose/virtual trajectory screen is not moving-body evidence. Preserve full unsummarized trial records and hashes.

**Internal neural and control gate:** all **3/3** approaches at **each** resolution must reach DNp01 ≥0.5 and a healthy EscapeDecoder stop while virtual boundary margin is strictly positive; **0/6** static/receding cases at each resolution may produce a healthy neural stop. All inputs and neural states must remain finite and healthy. An approach with no stop, late stop, or invalid neural lineage fails; do not remove it from the denominator.

**Paired resolution gate:** for every approach seed, absolute differences in first-positive looming time and first DNp01 ≥0.5 time between resolutions must each be **≤100 ms**, and peak LPLC2 ratio `129×65 / 65×33` must be in **[0.75, 1.333]**. A zero peak fails the ratio. These are the previously frozen numerical tolerances, carried forward without relaxation. Report actual differences, ratios, and boundary margins. If either gate fails, V2.1 internal screen is FAIL; retain the result and do not promote it to official Thor. Passing this small development screen supports recertification only, not a final success-rate claim.

## Separate temporal sampling test

Periods are 100/50/40 ms; the 150 ms gap rule remains fixed. Require the same per-resolution 3/3 preboundary neural stop and 0 control stops at each candidate cadence. Evaluate timing in elapsed milliseconds rather than frame counts; retain the paired first-looming/first-threshold tolerance of **100 ms at every tested cadence** and the same peak ratio interval [0.75, 1.333]. Choose the **lowest passing cadence** and freeze scheduler/TTL semantics before official recertification. A failure at 10 Hz cannot be hidden by a later faster-cadence pass: report it explicitly, and do not retroactively call the original 10 Hz hypothesis successful.

# P8-R2 — versioned visual looming representation test

Historical development draft PR #66 found **zero** healthy neural stops before
the frozen 0.25 m boundary in six official Thor development trials using the
P8-01 65×33 binary RGB disk. At 40 ms camera intervals, rounded pixel radius
left long constant target-area plateaus; positive looming/LPLC2 pulses were
sparse and graph-v2 DNp01 reached a stop only after the boundary in one trial.
An offline canonical-renderer comparison predicted that 129×65 pixels produce
more frequent but smaller area-growth pulses. This is a candidate, not a
demonstrated neural or behavioral improvement.

## Root cause and shutdown

`verify()` computed the SHA256 of the persisted `local-reference.json` as a local variable but returned only five other values. `run()` used `reference_hash` after opening robotd, state, and pose clients, before entering its cleanup `try/finally`. The resulting `NameError` escaped with a state subscriber thread alive, and the parent waited without a deadline. The 51 original tests exercised isolated local-reference, scorer, and harness components but never drove the actual trial entry point past reference verification with opened clients.

R1 validates and hashes the persisted canonical reference bytes before opening clients, returns that hash explicitly from `verify()`, checks it again before moving and before arm, and records it in the event, arm marker, and summary. The scorer compares all three and the journal with the persisted file. Client setup has an exception cleanup path. The trial supervisor enforces a frozen 30 s deadline; on a child that fails to exit, it sends SIGINT, then terminates and kills within bounded grace periods, records an interrupted/unknown-arm result without retry, invokes emergency stop, and still performs official down and the port/socket probe. A timed-out or unknown-arm trial cannot pass.
